
# NetShield — Network Intrusion Detection System

NetShield is a machine-learning-based web application for analyzing network-flow records and detecting potentially malicious traffic.

## Tech Stack

- Frontend: React.js, Vite.js, Tailwind CSS
- Backend: Django, Django REST Framework
- Database: PostgreSQL
- Machine Learning: TensorFlow/Keras, Scikit-learn
- Dataset: CIC-IDS2017
- Deployment: Vercel, Render

## Planned Features

- CSV network-flow upload
- Neural-network-based intrusion classification
- Traffic analysis dashboard
- Detection results and alert history
- Model performance evaluation
- Historical upload analysis

## Project Structure

- `backend/` — Django REST API
- `frontend/` — React application
- `ml/` — Dataset preprocessing, model training, and evaluation
- `docs/` — Project documentation

## Dataset

CIC-IDS2017, published by the Canadian Institute for Cybersecurity at the University of New Brunswick.

https://www.unb.ca/cic/datasets/ids-2017.html

## Scope

NetShield performs offline analysis of network-flow records. It is an educational and portfolio project, not a production-grade intrusion prevention system.
